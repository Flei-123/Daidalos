Daidalos ist Justins deterministische C++-Engine (Vulkan, eigener Editor, eigene Physik Talos). Darin ist ein Drohnenshow-Modus gebaut: project.daidalos hat ein Feld kind = game | droneshow, das dasselbe Binary auf ein anderes Panel-Set umschaltet. Die Pipeline steht: 3D-Modell -> Punktwolke sampeln (Mindestabstand als harte Nebenbedingung) -> Farbe je Punkt -> Zuordnung (Jonker-Volgenant exakt, ueber 2000 Drohnen geclusterte Auktion) -> Layering/Zeitversatz fuer kollisionsfreie Uebergaenge -> Validierung (Mindestabstand, v_max, a_max ueber die ganze Zeitachse) -> Export .skyc/.csv/.json. Skaliert gemessen bis 10.000 Drohnen. Zwei Gauntlet-Runden gelaufen (67, dann 70/100, Ziel 85).

Wenn die Rettung ein Paar wirklich nicht aufloesen kann, muss sie eine hoehere Ebene oeffnen oder den Uebergang zeitlich strecken — die Show muss danach echt fliegbar sein, mit demselben Mindestabstand.

DANACH, in dieser Reihenfolge, die Punkte aus der urspruenglichen Aufgabe, soweit sie noch schwach sind:
1. SAMPLING: N ist FIX (die Flotte hat 50 oder 100 Drohnen, nicht "so viele wie das Mesh hergibt"). Punkte gleichmaessig verteilen mit garantiertem Mindestabstand (Poisson-Disk / Lloyd-Relaxation), Silhouette/Kanten bevorzugt gewichten, weil das Publikum aus einer Richtung schaut. Ergebnis muss deterministisch sein (gleicher Seed, gleiche Punkte, bitweise).
2. FARBE je Punkt aus Vertex-Color oder Textur am Sample-Ort.
3. ZUORDNUNG: minimale Gesamtflugstrecke, exakt fuer kleine N, geclustert fuer grosse.
4. UEBERGAENGE: kollisionsfrei auch bei DICHTEN Formationen — genau da, wo Skybrush selbst nur "guaranteed collision-free if the formations are sparse enough" verspricht. Das ist der inhaltliche Mehrwert.
5. VALIDIERUNG: jede Regel einzeln pruefbar, Verstoss mit Paar-ID und Zeitstempel benannt, klickbar im UI.
6. GUI im Daidalos-Editor: Storyboard/Timeline, Parameter-Panel (Mindestabstand, v_max, a_max, Show-Origin GPS, Drohnenzahl), Vorschau im Viewport, Konfliktliste. Beim Anlegen eines Projekts die zwei Kacheln game / droneshow.
